# NBA Season Data Visualization

Interactive web visualization exploring NBA season statistics, team data and player comparison.

## Features

- Interactive main view with league data and map visualization (`index.html`, `img/us.svg`)
- Team detail view (`team.html`, `js/team.js`) with team logos (`logos/`)
- Structured NBA dataset (`data/nba.json`)

## Tech Stack

- HTML5, CSS3, JavaScript
- JSON data & SVG/Canvas visualization
